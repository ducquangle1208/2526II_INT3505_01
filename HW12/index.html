Giới thiệu chung

Hệ thống **AI E-Commerce API Suite** cung cấp các giải pháp mạnh mẽ tích hợp trí tuệ nhân tạo trực tiếp vào website bán hàng của bạn. Chúng tôi hỗ trợ tìm kiếm sản phẩm bằng ngôn ngữ tự nhiên, gợi ý sản phẩm cá nhân hóa độ chính xác cao và tối ưu hóa giỏ hàng (Smart Checkout).

Tất cả API được xây dựng trên chuẩn **RESTful**, sử dụng giao thức bảo mật bắt buộc là **HTTPS** và trả về định dạng dữ liệu duy nhất là **JSON**.

Base URL

https://sandbox.api.aiecom.vn/v1
Môi trường Sandbox: Mọi yêu cầu test trong quá trình phát triển nên gửi tới Base URL Sandbox ở trên. Dữ liệu là mock nhưng cấu trúc Schema hoàn toàn trùng khớp với môi trường Production chính thức.

Xác thực tài khoản

Mọi request gửi tới API cần chứa API Key bí mật nằm trong Header HTTP. API Key của bạn bắt đầu bằng tiền tố sk_live_ cho môi trường thật và sk_test_ cho môi trường Sandbox.

Bảo mật khóa API: Hãy giữ khóa API của bạn cẩn thận. Không nhúng trực tiếp API Key vào mã nguồn Frontend (Client-side JavaScript). Hãy gọi API thông qua Backend Proxy của bạn.

Header yêu cầu

Authorization: Bearer YOUR_API_KEY

Mã lỗi hệ thống

Chúng tôi sử dụng mã trạng thái HTTP tiêu chuẩn để báo cáo kết quả của request. Các mã lỗi trong khoảng 4xx biểu thị lỗi phía client (thiếu tham số, sai API Key), và mã lỗi trong khoảng 5xx biểu thị lỗi máy chủ.

Mã lỗi HTTP Mã lỗi JSON Ý nghĩa và Hướng khắc phục
400 Bad Request invalid_parameters Thiếu tham số bắt buộc hoặc kiểu dữ liệu không hợp lệ.
401 Unauthorized authentication_failed API Key không hợp lệ hoặc đã bị vô hiệu hóa.
429 Too Many Requests rate_limit_exceeded Vượt quá giới hạn cuộc gọi API cho phép trong gói cước hiện tại.
500 Server Error internal_error Lỗi hệ thống xử lý nội bộ. Hãy liên hệ bộ phận hỗ trợ.
GET /products/search-ai

Tìm kiếm AI (Semantic Search)

Thực hiện tìm kiếm ngữ nghĩa thông minh trên kho sản phẩm bằng ngôn ngữ tự nhiên. Phù hợp cho việc tích hợp tính năng chatbot mua sắm hoặc ô tìm kiếm AI thế hệ mới.

Tham số Query (Query Parameters)

Tham số Kiểu dữ liệu Yêu cầu Mô tả
q String Bắt buộc Câu lệnh tìm kiếm tự nhiên. Ví dụ: "giày chạy bộ nam êm chân màu đỏ"
limit Integer Tùy chọn (Mặc định: 10) Số lượng sản phẩm trả về tối đa (Tối đa 50).

Request ví dụ

curl -G https://sandbox.api.aiecom.vn/v1/products/search-ai \
  -H "Authorization: Bearer sk_test_123456" \
  --data-urlencode "q=giày chạy bộ màu đỏ" \
  -d "limit=2"
fetch('https://sandbox.api.aiecom.vn/v1/products/search-ai?q=giày chạy bộ màu đỏ&limit=2', {
  headers: {
    'Authorization': 'Bearer sk_test_123456'
  }
})
.then(res => res.json())
.then(data => console.log(data));
import requests

url = "https://sandbox.api.aiecom.vn/v1/products/search-ai"
headers = {"Authorization": "Bearer sk_test_123456"}
params = {"q": "giày chạy bộ màu đỏ", "limit": 2}

response = requests.get(url, headers=headers, params=params)
print(response.json())

POST /recommendations

Đề xuất sản phẩm cá nhân hóa

Phân tích hành vi xem/mua hàng gần đây của khách hàng để gợi ý danh sách các sản phẩm có tỷ lệ chốt đơn cao nhất.

Body Parameters (JSON)

Tham số Kiểu dữ liệu Yêu cầu Mô tả
user_id String Bắt buộc Mã khách hàng để phân tích hành vi lịch sử.
recent_viewed_ids Array of Strings Tùy chọn Mã các sản phẩm khách hàng vừa click xem trong phiên.
limit Integer Tùy chọn Hạn mức gợi ý trả về (Mặc định: 5).

Request ví dụ

curl -X POST https://sandbox.api.aiecom.vn/v1/recommendations \
  -H "Authorization: Bearer sk_test_123456" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "usr_9988",
    "recent_viewed_ids": ["prod_001"],
    "limit": 2
  }'
fetch('https://sandbox.api.aiecom.vn/v1/recommendations', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_test_123456',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    user_id: 'usr_9988',
    recent_viewed_ids: ['prod_001'],
    limit: 2
  })
})
.then(res => res.json())
.then(data => console.log(data));
import requests

url = "https://sandbox.api.aiecom.vn/v1/recommendations"

payload = {

    "limit": 2
}

response = requests.post(url, headers=headers, json=payload)

POST /checkout/smart

Smart Checkout (Giỏ hàng thông minh)

Phân tích giỏ hàng của người dùng, tự động đề xuất quà tặng kèm, mã giảm giá tối ưu nhất bằng AI và tính toán chi phí vận chuyển tối ưu.

Body Parameters (JSON)

Tham số Kiểu dữ liệu Yêu cầu Mô tả
items Array of Objects Bắt buộc Danh sách sản phẩm trong giỏ hàng. Mỗi object chứa id và quantity.
shipping_address String Bắt buộc Địa chỉ nhận hàng để AI tính toán quãng đường và chi phí ship.

Response mẫu thành công (200 OK)
